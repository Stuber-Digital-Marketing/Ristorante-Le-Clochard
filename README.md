# Ristorante Le Clochard

Site vitrine statique pour GitHub Pages / Cloudflare Pages.

## Fichiers

- `index.html` : page principale du site
- `assets/` : photos optimisées du restaurant
- `.nojekyll` : évite le traitement Jekyll sur GitHub Pages

## Mise en ligne sur GitHub

1. Créer un nouveau repository.
2. Uploader `index.html`, `.nojekyll` et le dossier `assets/` à la racine du repository.
3. Activer GitHub Pages dans Settings → Pages.

Important : le dossier `assets/` doit rester au même niveau que `index.html`, sinon les images ne s’afficheront pas.
